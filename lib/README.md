A **multi-purpose package installer**

---

This directory provides a collection of libraries for creating IPF packages, interacting with atrium, and developing 
custom deployers, as well as for integration with installrd. These libraries are used by 
[kcd](https://github.com/installr-io/installr-kcd), [ic](https://github.com/installr-io/ic), 
[ipf](https://github.com/installr-io/ipf), and [atrium](https://github.com/installr-io/atrium).
